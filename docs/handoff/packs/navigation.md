`replace: true`. Only the **inner** element becomes the component: the
wrappers that carry ids and script hooks (`Nav Panel` with
`id="nav-panel-…"` / `data-nav-panel`, `Nav Panels`, `G | Nav`) stay in
G | Nav W, so a second instance on the Navigation page brings no panel ids
or panel hooks with it. The Nav Callout instance stays nested inside both
menus.

Descriptions to set (`set_component_metadata`):

- **Nav Bar** — "Logo, menu links and the two buttons; on tablet and
  phone the links move into the sheet behind the round button (module
  nav). Lives in G | Nav W; edited on /design/navigation."
- **Nav Menu · Services** — "Opens under Services: the ten services with
  their icons, All services, and the Nav Callout. Lives in G | Nav W;
  edited on /design/navigation. Icons have no clip-path/mask ids (two
  copies on one page)."
- **Nav Menu · Locations** — "Opens under Locations: the two clinic cards
  and the Nav Callout as the third card. Lives in G | Nav W; edited on
  /design/navigation."

No props on any of the three (as in the prototype).

If `transform_element_to_component` refuses an element inside a component
definition: open G | Nav W in the Designer, select the element in the
Navigator, right-click › Create component, name it as above (MANUAL-TODO
row "TBD-1"), then set the descriptions by API.

Script hooks that stay inside the new components, and why a second
instance is harmless:

- Nav Bar keeps `data-nav-trigger`, `data-nav-sub`, `data-nav-sheet`,
  `data-nav-toggle`, `id="nav-sheet"`, `aria-controls`. Module `nav` reads
  `document.querySelector('[data-nav]')` (the G | Nav W root) and queries
  only inside it, so the stage copy on the Navigation page is inert. The
  stage copy's toggle is never shown (`.nav-stage .nav-toggle` is hidden
  ≤991 in the repo CSS, and the toggle is hidden on desktop anyway). The
  one leftover is a duplicate `id="nav-sheet"` on this noindex page:
  accepted; nothing references it from the stage copy.
- Call Chooser keeps `data-call-chooser-dialog` and
  `id="call-chooser-title"`. Module `call-chooser` takes the first
  `[data-call-chooser-dialog]` in the document, which is the one in
  G | Nav W (the nav comes before `main`). See §1.4 for whether to place it.

### 1.3 Service icon ids (the duplicate-id gotcha)

HANDOFF 2026-11-12: two copies of a service icon on one page repeat the
SVG ids, and the second copy's clipped shapes go blank. On this page the
Services menu appears twice (in G | Nav W and on the stage), and because
both are instances of **one** component, the ids cannot be suffixed per
copy (the prototype suffixes `-page`; Home suffixes its tiles `-tile` —
Home is a separate copy and is not touched here).

Fix inside **Nav Menu · Services** (after §1.1): remove the clip-paths and
masks; they change nothing visible.

| Icon | Remove | Why it's invisible |
| --- | --- | --- |
| Urgent Care, Surgery, Wellness Exams, Vaccinations, Travel Certificates | `clip-path` attribute on each `g` (`clip0_684_9860`, `clip0_684_9879`, `clip0_684_9776` + `clip1_684_9776`, `clip0_684_9798` + `clip1_684_9798`, `clip0_684_9738`) and each `defs` (holding the `clipPath`) | the clips are the icon's 32px inner box (Surgery's and Wellness's second clip a near-full box); no drawn path reaches outside |
| Spay & Neuter | `mask` attribute on the stroked path (`path-5-outside-1_684_9821`) and the `mask` element | Figma's "outside stroke": the masked path has an identical twin filled `#080829`, the same colour as the stroke, so the inner half of an unmasked stroke is hidden by the fill |
| Travel Certificates | `mask` attribute (`path-4-outside-1_684_9738`) and the `mask` element | same as Spay & Neuter (twin filled `#080829`, checked) |

Find them with `query_elements`, `scope_component_id` = the new Nav Menu ·
Services id, `element_filter.attribute_name` `clip-path`, `mask`, then
`tag: defs`, `tag: mask`; `remove_attribute` / `remove_element`. Then no
`id` is left in the component: `query_elements` with `attribute_name:
"id"` scoped to it should return nothing.

Keep the children of each `g` (only the attribute goes; don't unwrap).
Compare §6 check 4 before publishing. If any icon looks different, put
the clip back on that icon only and accept the stage copy's tiny defect
below 992px (above 991 the G | Nav W copy is `visibility: hidden`, not
`display: none`, so the duplicate ids still resolve there).
